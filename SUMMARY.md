### 3. **Код и утилиты**

#### `modules/config_loader.py` (ПЕРЕПИСАН)
- Полностью новый модуль для работы с двухуровневой конфигурацией
- **Функции:**
  - `load_config_defaults()` — загрузка публичного конфига
  - `load_config_secret()` — загрузка приватного конфига
  - `save_config_defaults()` — сохранение публичного конфига
  - `save_config_secret()` — сохранение приватного конфига (с правами 0o600)
  - `get_environment_config(env_name)` — конфиг окружения (prod/test)
  - `get_shm_dir()` — путь к RAM-диску
  - `get_telegram_config()` — конфиг Telegram с проверкой
  - `get_openai_config()` — конфиг OpenAI
  - `get_template_config(template_name)` — конфиг шаблона
  - `get_ai_prompt_template(template_name)` — AI промт-шаблон
  - Обратная совместимость: `load_config()`, `save_config()`

- **Особенности:**
  - Полная документация каждой функции
  - Примеры использования в docstrings
  - Правильная обработка ошибок с информативными сообщениями
  - Автоматическое создание папок
  - Установка прав доступа для приватного конфига

- **Коммит:** [867fc97](https://github.com/albazrov/schedule_nbc/commit/867fc972edf9975f80009025b4237f4772f1bd6c)

#### `migrate_config.py` (НОВЫЙ)
- Скрипт автоматической миграции со старого `config.json` на новую систему
- **Возможности:**
  - Загружает старый config.json
  - Разделяет параметры на публичные и приватные
  - Создаёт `config_defaults.json` и `config_secret.json`
  - Создаёт `config_secret.json.example` для других пользователей
  - Режим `--dry-run` для предварительного просмотра
  - Автоматическое создание резервных копий

- **Использование:**
  ```bash
  python3 migrate_config.py              # Автоматическая миграция
  python3 migrate_config.py --dry-run    # Просмотр без изменений
  ```

- **Коммит:** [6389775](https://github.com/albazrov/schedule_nbc/commit/6389775686d279517a96e325e9ff82ecf8d21d63)

## 🔒 Безопасность

### Что защищено
- ✅ Telegram токены
- ✅ OpenAI API ключи
- ✅ ID администраторов и пользователей
- ✅ Пути к локальным ресурсам

### Как это работает
1. **Разделение:** приватные данные в отдельном файле
2. **Исключение:** `config_secret.json` в `.gitignore`
3. **Права:** файл создаётся с правами `0o600` (только владелец)
4. **Шаблон:** `config_secret.json.example` показывает структуру
5. **Ошибки:** информативные сообщения при отсутствии приватного конфига

## 🚀 Как использовать

### Для новых пользователей
1. Клонируют репозиторий
2. Копируют `config_secret.json.example` → `config_secret.json`
3. Заполняют свои данные
4. Запускают бота

### Для существующих пользователей (с старым config.json)
1. `python3 migrate_config.py` — автоматическая миграция
2. Проверяют что всё работает
3. Удаляют старый `config.json`

### В коде
```python
# Вместо старого способа:
# import json
# with open("config.json") as f:
#     cfg = json.load(f)

# Используют новый способ:
from modules.config_loader import (
    load_config_defaults,
    get_telegram_config,
    get_template_config
)

defaults = load_config_defaults()
telegram = get_telegram_config()
template = get_template_config("template_16_9")
```
